# Vector Strike downloads

Vector Strike is an arcade car-soccer game for Windows and Android. Website: https://vector-strike.com

This repository holds only the release files. Get them from the [Releases](../../releases/latest) page.

## Windows
1. Download `VectorStrike-Windows-<version>.zip` and unzip it to a folder.
2. Run `VectorStrike.exe`.
3. Requirements: Windows 10 or 11 (64-bit), a DirectX 12 graphics card. If the game reports a missing DLL, install the [Microsoft Visual C++ Redistributable (x64)](https://aka.ms/vs/17/release/vc_redist.x64.exe).

## Android
1. Download `VectorStrike-<version>-arm64.apk` on your phone.
2. Open it and allow installs from your browser when Android asks.
3. Requirements: 64-bit Android phone (arm64), Android 8 or newer recommended.

These are preview builds. Privacy policy: https://vector-strike.com/privacy
